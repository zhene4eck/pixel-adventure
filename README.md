# Пиксельное приключение

Мобильная мини-игра из трёх независимых уровней:
1. Накорми Эмму
2. Собери мотоцикл
3. Гидроцикл

После прохождения всех трёх открывается отдельная финальная страница.

## GitHub Pages
1. Создай новый репозиторий на GitHub, например `pixel-adventure`.
2. Загрузи **содержимое этой папки**, чтобы `index.html` лежал в корне репозитория.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`, затем Save.
6. Через некоторое время GitHub даст адрес вида `https://ТВОЙ-НИК.github.io/pixel-adventure/`.

Важно: загружай именно файлы и папку `games`, а не только `index.html`.
